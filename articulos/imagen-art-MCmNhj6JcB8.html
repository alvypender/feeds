Claude Opus 5.5 crea un juego completo para Steam en 2 días y por 50 dólares: código en JavaScript, arte con Rangy, modelos 3D con Meshy y audio con ElevenLabs

Por Pouya Eti 2026-11-12
▶ Ver video original en YouTube ↗
Pouya Eti ha demostrado que se puede crear un videojuego para Steam sin escribir una línea de código y sin motor de juego, usando Claude Opus 5.5 dentro de Claude Code. En solo dos días y con un gasto de unos 50 dólares, generó 'Just One More Star', un juego completo con 244 imágenes, modelos 3D, música y efectos de sonido. El flujo conecta Claude con Rangy, Meshy y ElevenLabs mediante MCP y claves API, y el resultado ya tiene una demo de 2-3 niveles lista para Steam.

El experimento: un juego sin motor y sin código

Pouya Eti, desarrollador y creador de contenido, se propuso un reto ambicioso: construir un videojuego completo para Steam sin utilizar un motor gráfico tradicional como Unity o Unreal, y sin escribir código manualmente. Su única herramienta de programación sería Claude Opus 5.5, el modelo de lenguaje de Anthropic, ejecutándose dentro de Claude Code, la extensión de VS Code que permite al agente escribir y modificar archivos directamente en el proyecto.

El juego resultante, bautizado como Just One More Star, es un título de acción y plataformas en el que controlamos a un personaje con un gancho y una cadena. La premisa es sencilla pero efectiva: enganchar enemigos, lanzarlos por los aires o estamparlos contra paredes y edificios. El objetivo es claro: demostrar que con las herramientas de IA actuales se puede crear un producto vendible con una inversión mínima y en tiempo récord.

El proceso completo se documentó en un vídeo donde Eti muestra cada paso, desde la instalación de Claude Code hasta la generación de la demo que planea subir a Steam. La clave del éxito no fue pedirle a Claude que hiciera el juego entero de una vez, sino trabajar de forma iterativa: describir la idea, jugar cada build de prueba y dar instrucciones concretas sobre qué conservar y qué cambiar. Este enfoque de conversación continua permitió refinar el game feel y ajustar detalles que marcan la diferencia.

Configuración del entorno: Claude Code y el poder de MCP

El primer paso fue instalar Claude Code como extensión en Visual Studio Code. El proceso es sencillo: abrir VS Code, ir a la sección de extensiones, buscar 'Claude Code', instalarla e iniciar sesión con una cuenta de Anthropic. Una vez activa, se abre un chat lateral donde se le pueden dar instrucciones al agente. Como alternativa, Eti menciona que también se puede usar la aplicación de escritorio de Claude, aunque la integración con VS Code facilita la gestión de archivos y la ejecución del código.

La verdadera potencia del flujo reside en el Model Context Protocol (MCP), un estándar que permite a Claude conectarse a aplicaciones externas. En este caso, Eti utilizó MCP para enlazar Claude con Rangy, su propia aplicación de generación de imágenes por IA. El proceso es tan simple como instalar y abrir la app de Rangy en Mac o Windows; Claude detecta el servidor MCP y puede enviar solicitudes de generación de imágenes directamente, aprovechando los precios más bajos del mercado.

Para las demás herramientas, Claude no accede directamente al código de las APIs por motivos de privacidad, pero sí puede utilizarlas si se le proporciona una clave guardada en un archivo local. Eti creó un archivo con la API key de Meshy y le indicó a Claude que podía leerlo para conectarse y generar modelos 3D. Lo mismo hizo con ElevenLabs para la generación de audio. Esta estrategia permite que el agente orqueste múltiples servicios sin exponer las credenciales en el código.

Generación de arte: 244 imágenes y el salto al 3D

Con el entorno listo, Claude comenzó a generar los assets visuales. Primero creó los conceptos de personajes, enemigos, objetos, texturas y edificios como imágenes 2D utilizando Rangy. En total, se generaron aproximadamente 244 imágenes, de las cuales Eti seleccionó las mejores para convertirlas en modelos 3D. Este paso intermedio es crucial: permite iterar rápidamente sobre el diseño antes de invertir tiempo y recursos en la geometría tridimensional.

La conversión a 3D se realizó con Meshy, una plataforma que transforma imágenes o prompts en modelos 3D. Claude, usando la API key almacenada, envió las imágenes seleccionadas y descargó los modelos resultantes. Eti muestra cómo el edificio principal del concepto 2D aparece en el juego con el mismo diseño, material y colores, lo que valida la fidelidad del pipeline. Además, se le indicó explícitamente a Claude que podía usar Blender si necesitaba crear o modificar modelos, y el agente abrió el software gratuito para realizar ajustes según convenía.

El coste de esta fase fue de 10 dólares para las imágenes con Rangy y 10 dólares para el plan de Meshy. Una inversión mínima si se compara con la contratación de artistas o la compra de assets en tiendas digitales, y que además otorga una coherencia visual completa al juego.

Audio dinámico: música, efectos y páginas de revisión

La banda sonora y los efectos de sonido se generaron con ElevenLabs. Claude recibió instrucciones de crear música distinta para cada nivel, situación, batalla y pelea contra jefes. Además, se exigió que todas las pistas musicales tuvieran una parte de loop para que el jugador no percibiera la repetición. Los efectos incluyen sonidos como pasos sobre hierba al caminar o correr, y la voz de un announcer que narra los eventos del juego.

Una de las innovaciones del flujo fue la generación automática de páginas de revisión de audio. Claude creó interfaces web donde Eti podía escuchar cada sonido generado y marcarlo como 'keep' o 'redo' antes de integrarlo en el juego. Esta funcionalidad demuestra la capacidad del agente para no solo generar contenido, sino también construir herramientas de control de calidad que facilitan la curaduría humana.

El coste del audio fue de 9,20 dólares para la música, 1,71 dólares para los efectos y 0,05 dólares para la voz del announcer. En total, menos de 11 dólares por un paquete de audio completo y personalizado.

Refinando el 'game feel': la conversación como herramienta de diseño

El primer resultado no fue el definitivo. Eti dedica una parte importante del vídeo a mostrar cómo iteró con Claude para mejorar el game feel. Por ejemplo, le pidió que los enemigos se destrozaran al golpear paredes, o que el gancho cambiara de aspecto y se alargara al mejorar. Estas peticiones se traducen en ajustes de código que Claude implementa y prueba en tiempo real.

El diseño del juego se centra en un gancho y una cadena: enganchar enemigos, lanzarlos fuera o estamparlos contra paredes y edificios. Los enemigos disparan bombas y hay un jefe con armadura pesada que debe ser arrancada por capas. Para que el jugador pueda ajustar la experiencia, se incluyó un menú de ajustes con volúmenes separados de ambiente, efectos, música y master, además de la posibilidad de desactivar sonidos para comprobar la mezcla.

Este enfoque de conversación continua es clave para obtener un resultado pulido. No se trata de pedir el juego completo de una vez, sino de construir sobre versiones funcionales y dar instrucciones específicas. Claude actúa como un programador y diseñador que responde a las indicaciones del humano, que mantiene el control creativo.

Costes, lanzamiento en Steam y expectativas

El coste total del experimento fue de 30,96 dólares en APIs (10 de Rangy, 10 de Meshy, 9,20 de ElevenLabs para música, 1,71 para efectos y 0,05 para la voz). Sumando el plan de Claude de 20 dólares, la inversión asciende a unos 50 dólares y dos días de trabajo. Una cifra ridícula si se compara con los presupuestos habituales de desarrollo de videojuegos.

El plan de lanzamiento es subir primero una demo de 2-3 niveles a Steam para captar wishlists y luego publicar el juego completo a un precio de 2-4 dólares. Steam cobra una tasa de 100 dólares por juego, que se reembolsa tras alcanzar los 1.000 dólares en ventas. Eti confía en que el juego genere ingresos suficientes para recuperar la inversión y obtener beneficios.

La conclusión del vídeo es optimista: el sistema permite crear un videojuego, hacer marketing con vídeos y aspirar a miles de dólares de ingresos con una inversión de unos 50 dólares. Si bien el resultado no es un AAA, sí es un producto vendible y funcional que demuestra el potencial de las herramientas de IA actuales para democratizar la creación de videojuegos.
