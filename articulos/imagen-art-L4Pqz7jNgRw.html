Cómo funcionan los códigos sref y por qué esta colección es útil

Midjourney permite aplicar un estilo visual concreto a cualquier prompt mediante el parámetro --sref seguido de un código numérico. Thaeyne ha seleccionado 50 códigos que comparten una paleta pastel, pero que cubren un espectro enorme: desde lo cute y lo gótico hasta lo surrealista y lo arquitectónico. La utilidad de esta colección radica en que ofrece un atajo para explorar variaciones estilísticas sin necesidad de describir cada detalle en el prompt; basta con añadir el código al final y el modelo aplicará automáticamente la estética asociada.

Para usar un estilo, simplemente escribe tu prompt habitual y añade --sref [código]. Por ejemplo, si quieres un retrato con acuarela pastel de Asia Oriental, usarías el código correspondiente a ese estilo. Thaeyne recomienda combinar estos códigos con otros parámetros como --ar para la relación de aspecto o --v para la versión del modelo, y experimentar con la intensidad del estilo mediante --sref con pesos si se desea un efecto más sutil.

Un muestrario de estilos: del gótico pastel al vidrio líquido

La colección incluye estilos tan diversos como el gótico whimsical con verdes y azules pálidos, ideal para ilustraciones de fantasía oscura pero suave; el anime lo-fi con cielos rosas y azules pizarra, perfecto para escenas nostálgicas; o el surrealismo botánico con renderizado 3D y estética editorial, que combina formas orgánicas con una paleta melocotón y lavanda. También hay espacio para la arquitectura surrealista con bloques gráficos, los doodles de Asia Oriental con personajes somnolientos, y las esculturas 3D de vidrio líquido con reflejos ray-traced, que aportan un toque de lujo translúcido.

Cada estilo se describe con detalle: desde pinceladas de óleo direccionales en mint, periwinkle y lavanda, hasta ilustraciones planas con textura de serigrafía y arcos geométricos. Thaeyne muestra ejemplos visuales de cada uno para que el usuario pueda evaluar rápidamente si encaja con su proyecto. La variedad temática es amplia: retratos de fantasía, paisajes chinos brumosos, ciudades con nubes rosas, criaturas creepy-cute, interiores retro-futuristas y composiciones minimalistas con coral y blanco lechoso.

Cómo adaptar estos estilos a otras herramientas de generación de imágenes

No todos los usuarios de generación de imágenes por IA utilizan Midjourney. Thaeyne sugiere que, para herramientas como Stable Diffusion, DALL-E o Leonardo AI, se puede capturar una imagen de referencia del estilo deseado y subirla como imagen de guía o utilizar la función de image prompt si está disponible. En el caso de Stable Diffusion, también se puede emplear ControlNet con la imagen de referencia para transferir el estilo, o entrenar un LoRA específico si se va a usar repetidamente.

Otra alternativa es extraer la paleta de colores y las características visuales dominantes (como el tipo de pincelada o la iluminación) y describirlas en el prompt de texto. Sin embargo, la ventaja de los códigos sref es su inmediatez y consistencia, por lo que si se trabaja con Midjourney, esta biblioteca ahorra mucho tiempo. Thaeyne recomienda guardar los códigos favoritos en un documento o utilizar la función de favoritos de Midjourney para tenerlos siempre a mano.

Consejos prácticos para integrar estos estilos en tu flujo de trabajo

Para obtener mejores resultados, Thaeyne aconseja combinar el código sref con un prompt descriptivo que incluya el sujeto, la composición y la iluminación deseados. Por ejemplo, un prompt como 'retrato de una mujer con vestido victoriano, iluminación suave, --sref 12345' aplicará el estilo pastel gótico al retrato. También se puede ajustar la fuerza del estilo añadiendo un peso al parámetro, como --sref 12345::2 para duplicar su influencia, o --sref 12345::0.5 para reducirla.

Es importante tener en cuenta que los códigos sref están vinculados a la versión del modelo de Midjourney; si se actualiza la versión, los estilos pueden variar ligeramente. Thaeyne sugiere probar cada código con un prompt sencillo para calibrar su efecto antes de aplicarlo a proyectos complejos. Además, recomienda no abusar de la paleta pastel en todos los elementos: a veces un toque de contraste (por ejemplo, un acento en negro o dorado) puede realzar la composición sin perder la suavidad general.

Claves prácticas para recordar

  • Para aplicar un estilo: añade '--sref [código]' al final de tu prompt en Midjourney.
  • Ajusta la intensidad del estilo con pesos: '--sref [código]::2' para el doble de influencia, '::0.5' para la mitad.
  • En otras herramientas, usa una captura del estilo como imagen de referencia o entrena un LoRA para consistencia.
