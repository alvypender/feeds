Claude + Blender: el método definitivo para crear referencias 3D y generar videos IA con Seedance 2.5

Por Dan Kieft 2026-11-16
▶ Ver video original en YouTube ↗
La generación de video con IA alcanza un nuevo nivel de control gracias a la combinación de Blender, Claude y Seedance 2.5. Dan Kieft demuestra en un curso completo que crear escenas 3D low-poly como referencia visual permite dirigir la cámara con precisión milimétrica, mantener la consistencia de personajes y ahorrar créditos. El flujo básico usa el plugin de Higgsfield en Blender; el avanzado, Claude Code con MCP para construir escenas desde cero. El veredicto es claro: esta integración supera las limitaciones del prompting tradicional y se posiciona como el estándar para producciones profesionales.

El problema del prompting tradicional y la solución 3D

Los generadores de video IA como Seedance 2.5 han revolucionado la creación audiovisual, pero siguen arrastrando un problema fundamental: el prompting basado solo en texto es impredecible. Describir un movimiento de cámara complejo o mantener la coherencia de un personaje a lo largo de varias tomas se convierte en una lotería que consume créditos y tiempo. Dan Kieft, experto en flujos de trabajo con IA, propone un cambio de paradigma: en lugar de escribir interminables prompts, construir una escena 3D en Blender que sirva como referencia visual exacta. Esta técnica, que él llama 'previsualización 3D', permite definir ángulos, trayectorias y composición antes de gastar un solo crédito en el generador.

La clave está en la simplicidad. Kieft recomienda crear escenas low-poly, sin detalles excesivos, para que el equipo no se sobrecargue y la IA pueda interpretar la referencia sin ambigüedades. Blender, siendo gratuito y de código abierto, se convierte en el aliado perfecto. Pero el verdadero salto de calidad llega cuando se integra Claude, el modelo de lenguaje de Anthropic, para automatizar la creación de la escena. Con la versión adecuada, como Claude Opus 5.5, y el protocolo MCP (Model Context Protocol), es posible pedirle a Claude que construya la escena directamente en Blender mediante instrucciones en lenguaje natural. El resultado es un video de referencia que Seedance 2.5 puede seguir con precisión, eliminando la incertidumbre del prompting ciego.

Flujo básico: Higgsfield en Blender para escenas rápidas

El primer flujo de trabajo que Kieft presenta está diseñado para quienes quieren resultados rápidos sin sumergirse en la programación. Consiste en instalar el plugin de Higgsfield para Blender, una herramienta que permite generar escenas 3D directamente desde un prompt de texto dentro del propio Blender. El proceso es sencillo: se activa el MCP Control en el panel de Higgsfield, se escribe una descripción de la escena deseada y el plugin se encarga de crear la geometría básica. Kieft demuestra con un ejemplo: un hombre llegando a casa. La generación tomó entre 5 y 10 minutos, dependiendo de la complejidad, y produjo una animación esquemática pero funcional como referencia de cámara.

Una de las ventajas de este flujo es la iteración rápida. Si se quiere añadir un detalle, como un bebé en brazos de la mujer, basta con modificar el prompt en el Scene Builder y la escena se actualiza. Para exportar la referencia, se configura la salida en formato MP4 con códec H264 y se renderiza la animación. Kieft insiste en la importancia de guardar frecuentemente el archivo con File > Save As para evitar pérdidas por crashes. Aunque el resultado visual es tosco, cumple su función: proporcionar a Seedance 2.5 una guía espacial y temporal que el generador de video puede seguir con exactitud. Este método es ideal para creadores que ya tienen una suscripción a Higgsfield y buscan una solución accesible.

Flujo avanzado: Claude Code y MCP para un control total

Para quienes buscan un control absoluto y están dispuestos a configurar un entorno más técnico, Kieft desglosa el flujo avanzado con Claude Code y el protocolo MCP. El primer paso es conectar Blender MCP a Claude: en la configuración de Claude, se accede a Settings > Customize > Connectors, se busca 'Blender' y se instala. Luego, se sigue el instructivo disponible en blender.lab para configurar el servidor MCP. En Blender, es necesario activar 'Allow Online Access' en Preferences > System > Network, y en la sección de Add-ons, habilitar y arrancar el MCP Bridge Server. Para verificar que la conexión funciona, se le pregunta a Claude 'am I connected to blender?' y este responde afirmativamente.

Con la conexión establecida, el proceso creativo se acelera. Kieft muestra cómo generó un terrario con Seedream 5.0 y lo usó como referencia para que Claude MCP construyera una escena en Blender. Tras varios ajustes de escala y densidad de vegetación, obtuvo una base simplificada que luego detalló en Seedance 2.5. Este flujo permite que Claude tome decisiones de construcción, pero Kieft advierte: 'No dejes que Claude tome decisiones creativas por ti; ten una idea clara antes de empezar'. Si no puedes visualizar la escena, crear un storyboard previo es fundamental. La recompensa es un control sin precedentes: la escena 3D resultante se exporta como video de referencia y Seedance 2.5 la sigue al pie de la letra, respetando ángulos, encuadre y trayectoria continua.

Del 3D al video final: referencias visuales y de audio

El puente entre Blender y Seedance 2.5 no termina con el video de referencia. Kieft introduce el concepto de 'visual anchors': capturas de pantalla de la escena en Blender que se transforman en imágenes realistas con Nano Banana Pro a 2K. Estas imágenes se utilizan como referencia de estilo en Seedance 2.5, asegurando que la estética del video final coincida con la visión original. Además, para mantener la consistencia de los personajes, recomienda generar character sheets detallados y usarlos como referencia. Al promptear en Seedance 2.5, es crucial etiquetar claramente cada imagen de referencia (por ejemplo, 'image 1: wife', 'image 2: hallway') para que la IA entienda su rol. Verificar que las referencias subidas coincidan con las etiquetas del prompt antes de generar evita gastar créditos innecesariamente.

La consistencia vocal también es tratada con rigor. Kieft incluye referencias de audio (su propia voz y la de otros personajes) para que Seedance 2.5 mantenga el timbre y la entonación en el video generado. Ajusta la duración del video para que coincida con la referencia de Blender (por ejemplo, 25 segundos) y utiliza la versión Draft para pruebas rápidas, upscaleando luego a 1080p. El resultado, comparado con la referencia, sigue exactamente los movimientos de cámara (overhead, descenso, paneo, tilt) y mantiene la coherencia visual. Esta meticulosidad convierte a Blender en un aliado indispensable para producciones que requieren precisión cinematográfica.

Automatización de prompts con skills personalizadas

Para agilizar aún más el flujo, Kieft muestra cómo instalar skills personalizadas en Claude o ChatGPT. En Settings > Customize > Skills > Add > Upload Skill, se puede cargar una habilidad que genere prompts automáticamente para Seedance 2.5. Él utiliza el comando '/Seedance 2.5 prompter' para obtener prompts detallados a partir de una descripción breve. Esta automatización ahorra tiempo y reduce errores, especialmente cuando se trabaja con múltiples tomas. La skill está disponible en el enlace claude-and-blender.vercel.app, y su uso se integra perfectamente con los flujos anteriores.

Kieft enfatiza que estas skills no reemplazan la creatividad humana, sino que la potencian. Al tener una idea clara y un storyboard previo, la skill puede generar variaciones de prompts que exploran ángulos o estilos sin desviarse de la visión. Combinado con las referencias 3D, el prompting se vuelve una tarea de precisión, no de azar. El curso concluye que dominar estas herramientas permite a los creadores competir en la liga de la producción profesional, donde el control y la consistencia son la diferencia entre un video genérico y uno memorable.

Claves prácticas para recordar

  • Para moverte en Blender: rueda del ratón para zoom, clic central para rotar, Shift+clic central para desplazar, tecla 0 para volver a la cámara activa.
  • Exporta la referencia en MP4 H264 desde Output > Render Animation.
  • Verifica la conexión MCP preguntando a Claude: 'am I connected to blender?'.
  • Etiqueta cada imagen de referencia en el prompt de Seedance 2.5 (ej: 'image 1: wife') para evitar confusiones.
