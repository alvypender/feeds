Ver en YouTube: 3 psychedelic SREF codes (Thaeyne [Short])

El video muestra tres códigos SREF de Midjourney (4034, 4838 y 6210) que producen estilos visuales psicodélicos. Cada código se acompaña de un prompt base con parámetros de relación de aspecto, versión y semilla. Es un extracto de un video más largo sobre 50 estéticas de arte psicodélico.

  • Usa el código SREF 4034 con el prompt: --sref 4034 --ar 9:16 --v 8.2 --seed 777 para obtener un estilo psicodélico con ojos y setas.
  • Usa el código SREF 4838 con el prompt: --sref 4838 --ar 9:16 --v 8.2 --hd --seed 777 para un estilo con figuras humanoides y colores vibrantes.
  • Usa el código SREF 6210 con el prompt: --sref 6210 --ar 9:16 --v 8.2 --hd --seed 777 para un estilo con paisajes y motivos florales.
  • El autor presenta tres códigos SREF que generan estilos psicodélicos distintos, mostrando ejemplos visuales para cada uno. No se realizan comparaciones ni experimentos detallados, solo se exhiben los resultados.
