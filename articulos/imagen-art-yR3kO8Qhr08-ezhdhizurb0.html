Siete códigos SREF de Midjourney permiten replicar estéticas oníricas e iridiscentes sin escribir prompts complejos: el 3608, 3833 y 4976 generan paisajes cósmicos, ciudades celestiales y escenas místicas; el 610159022, 324757786, 1544328325 y 2362343651 transforman el prompt 'iridescent' en retratos de plumas, abstracciones geométricas, psicodelia y neón. La clave está en fijar seed 777 y --ar 9:16 para aislar el efecto del estilo y comparar resultados.

El método Thaeyne: una variable, un estilo

La demostración de Thaeyne no es una colección de imágenes bonitas, sino un experimento controlado. En ambos shorts se mantienen constantes el seed 777, el aspect ratio 9:16 y, en el segundo, el parámetro --hd; la única variable que cambia es el código --sref. Así, cualquier diferencia visual se atribuye al estilo referenciado y no al azar de la generación. Este enfoque convierte los códigos en herramientas reproducibles: el lector puede copiar el prompt, pegar el código y obtener una estética muy cercana a la mostrada.

El formato vertical --ar 9:16 no es casual: está pensado para Shorts, Reels y TikTok, donde el encuadre vertical domina. La versión --v 6.0 de Midjourney es la base en el primer video, mientras que el segundo añade --hd para forzar alta definición. Ninguno de los dos videos incluye precios o planes de suscripción; el valor está en los códigos y en la lógica de comparación.

Tres códigos para mundos oníricos: 3608, 3833 y 4976

El primer short presenta tres SREF que producen estilos oníricos con temáticas distintas. El código 3608 genera paisajes surrealistas con formaciones rocosas brillantes y cielos cósmicos, como si la escena flotara entre cavernas y nebulosas. El prompt completo es --sref 3608 --ar 9:16 --v 6.0 --seed 777. El código 3833 se inclina por ciudades futuristas de arquitectura grandiosa y cuerpos celestes, con una escala que mezcla lo urbano y lo celestial; su prompt es --sref 3833 --ar 9:16 --v 6.0 --seed 777.

El código 4976 cierra la trilogía con escenas místicas nocturnas, iluminación azul, agua y elementos etéreos. Aquí Thaeyne añade el parámetro --hd para mayor detalle o resolución, quedando el prompt como --sref 4976 --ar 9:16 --v 6.0 --hd --seed 777. Los tres códigos son numéricos y se activan con el prefijo --sref; no requieren una imagen de referencia externa, solo el número. La invitación final del video a ver la versión completa sugiere que existen más códigos, pero los tres mostrados ya cubren paisaje, ciudad y escena mística.

Un mismo prompt, cuatro estéticas: el experimento 'iridescent'

El segundo short lleva la lógica al extremo: el prompt base es una sola palabra, 'iridescent', y se mantienen fijos --seed 777, --ar 9:16 y --hd. Al cambiar únicamente el SREF, el resultado pasa de un retrato con plumas o escamas naranjas a una abstracción digital, a un retrato psicodélico y a una composición neón. La conclusión es directa: --sref altera drásticamente la estética final aunque el prompt y el seed sean idénticos, lo que lo convierte en una herramienta ideal para explorar direcciones visuales desde una misma idea.

El código 610159022 produce un perfil femenino con plumas o escamas naranjas iridiscentes, un acabado orgánico y brillante. El código 324757786 genera una estética digital abstracta con partículas geométricas azules y moradas sobre un rostro. El código 1544328325 lleva a un retrato psicodélico con patrones arremolinados de azules, verdes, naranjas y amarillos. El código 2362343651 cierra con una composición luminosa de gafas iridiscentes, cabello neón y efecto bokeh. En los cuatro casos, el prompt completo sería iridescent --sref [código] --ar 9:16 --hd --seed 777.

Cómo reutilizar los códigos más allá del prompt original

La recomendación implícita de Thaeyne es tratar los SREF como presets de estilo: una vez identificado el código que produce la estética deseada, se puede trasladar a otros prompts. Por ejemplo, el 3608 no está atado a paisajes cósmicos; puede aplicarse a un retrato o a un bodegón para impregnarlo de esa atmósfera de roca brillante y cielo estrellado. Lo mismo ocurre con el 2362343651, cuyo neón y bokeh pueden funcionar en una escena urbana o en un producto.

Para que la comparación sea válida, conviene mantener el seed fijo mientras se prueba un mismo prompt con distintos SREF; una vez elegido el estilo, se puede variar el seed para explorar composiciones. El aspect ratio 9:16 es útil para contenido móvil, pero nada impide cambiarlo a 16:9 o 1:1 una vez identificado el código. La única precaución es que el SREF y el seed no son excluyentes: el seed controla la variación aleatoria, el SREF controla la estética, y ambos pueden combinarse con otros parámetros como --v 6.0 o --hd.

Lo que estos shorts no resuelven

Ninguno de los dos videos realiza comparaciones con fallos, pruebas de precio o análisis de límites del plan de Midjourney; son demostraciones visuales puras. Tampoco se muestra el proceso de obtención de los códigos ni se explica cómo buscar nuevos SREF. El valor periodístico está en la lista concreta de siete códigos y en la metodología de variable única, no en una evaluación crítica de la herramienta. Para quien busque reproducir los resultados, los prompts completos y los parámetros fijos son el dato accionable; para quien busque entender el costo, habrá que consultar la web oficial de Midjourney, que no se enlaza en la descripción.
