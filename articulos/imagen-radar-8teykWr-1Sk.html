Cuatro códigos SREF de Midjourney para transformar el prompt 'fairytale' en estilos visuales únicos

Ver en YouTube: fairytale - 4 SREF styles (Thaeyne [Short])

El video muestra cuatro estilos visuales generados con Midjourney usando el prompt 'fairytale' y diferentes códigos SREF. Cada estilo se presenta con su código SREF específico y parámetros como semilla y relación de aspecto. El video concluye con una pantalla que invita a guardar los códigos SREF para replicar los estilos. Es un tip rápido para artistas que buscan inspiración en estilos de cuento de hadas.

  • Usa el prompt 'fairytale' junto con un código SREF para obtener estilos predefinidos.
  • Parámetros recomendados: --ar 9:16 para formato vertical, --hd para alta definición, --v 8.2 para la versión del modelo.
  • Puedes cambiar la semilla (--seed) para variar la composición manteniendo el estilo.
  • Se generaron cuatro imágenes con el mismo prompt 'fairytale' pero diferentes códigos SREF, mostrando variaciones estilísticas que van desde un vestido luminoso hasta un estilo psicodélico con setas y un estilo pictórico de princesa en un castillo.
  • Conclusión: los códigos SREF permiten explorar rápidamente distintos estilos visuales para un mismo concepto.
