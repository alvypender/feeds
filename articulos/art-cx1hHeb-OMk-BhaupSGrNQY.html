Anthropic entierra a los agentes especializados: un solo agente con 'skills' modulares y las 10 habilidades gratuitas que lo potencian

Por Xavier Mitjana + Aztec Lab 2026-11-26
▶ Ver video original en YouTube ↗
Los ingenieros de Anthropic ya no construyen agentes dedicados: apuestan por un agente general que carga 'skills' bajo demanda, un cambio de paradigma que Xavier Mitjana desglosa en seis niveles de gestión. En paralelo, Aztec Lab presenta las diez skills de código abierto más populares para Claude Code, desde humanizar textos hasta dotar de memoria al agente. El veredicto: las skills capturan el 'oficio' que los modelos no tienen, pero instalar sin revisar es un riesgo de seguridad y acumular instrucciones obsoletas puede 'atar' al modelo.

El fin del agente especializado: por qué Anthropic prefiere un genio con oficio

Durante meses, la receta para automatizar tareas con IA parecía clara: crear un agente para cada función, con instrucciones y herramientas a medida. Sin embargo, los ingenieros de Anthropic —con Barry Zhang a la cabeza— detectaron un patrón incómodo: los agentes especializados fallaban no por falta de inteligencia, sino por desconocer el 'oficio', ese conjunto de reglas implícitas, datos de clientes, identidad de marca y correcciones que definen cómo se hace el trabajo en cada empresa. La analogía que usa Xavier Mitjana en su análisis es reveladora: un genio de las matemáticas no es lo mismo que un asesor fiscal con años de experiencia; el primero puede resolver ecuaciones complejas, pero el segundo sabe qué gastos son deducibles y cómo tratar a un cliente moroso.

La solución que adoptaron fue radical: en lugar de muchos agentes, un único agente general —como Claude Code— que carga 'skills' (habilidades) bajo demanda. Cada skill es un paquete de instrucciones, datos y ejemplos que se activa solo cuando la tarea coincide con su descripción. Así, el agente puede tener cientos de habilidades sin saturar su contexto, porque solo lee la descripción breve y abre las instrucciones completas cuando hace falta. Antes, meter todo en un solo agente saturaba la ventana de contexto y provocaba que ignorara partes enteras de las instrucciones; con el enfoque modular, ese problema desaparece.

El cambio no es cosmético: redefine la forma de trabajar con IA. Ya no se trata de programar agentes, sino de capturar conocimiento. Y ahí entra el 'oficio': las skills son el vehículo para transmitir ese conocimiento tácito que los modelos no pueden inferir por sí solos.

Los seis niveles para crear y gestionar skills: del 'pídeselo a Claude' al borrado periódico

Mitjana estructura el proceso en seis niveles de complejidad creciente. El primero es el más obvio: pedirle a Claude que escriba la skill. Usando la skill nativa Skill Creator, incluida en la app de Claude, basta con describir la tarea y adjuntar ejemplos de tu trabajo —propuestas, correos, informes— para que el modelo copie estructura y tono. Es útil cuando tienes reglas claras o ejemplos representativos, pero falla si la tarea es difícil de explicar con palabras, como redactar un correo delicado. Un truco: añade en tus instrucciones generales que Claude use Skill Creator siempre que le pidas una skill nueva, para que siga buenas prácticas desde el principio.

El segundo nivel es el que Mitjana recomienda para la mayoría de tareas repetitivas: realizar la tarea una vez con Claude y, al final, pedirle que convierta toda la sesión en una skill con Skill Creator, incluyendo las correcciones que hayas hecho. Así se capturan los ajustes implícitos que de otro modo se perderían. El tercer nivel lleva esto al terreno visual: grabar la pantalla directamente en la app de Claude (botón +, 'grabar una skill') mientras explicas lo que haces. Claude revisa la grabación y propone una skill. Para tareas con interacción visual —navegar una web, descargar datos de un portal— es la vía más eficaz, porque las palabras se quedan cortas. Si prefieres grabar con OBS Studio o Windows+G, puedes subir el video, pero conviene configurar una skill que haga transcripción segundo a segundo para que Claude sepa qué decías en cada momento.

El cuarto nivel introduce la modularidad: crear skills separadas de datos (información de clientes), diseño (identidad visual) y definiciones (qué significa un término para tu organización), y combinarlas con las skills de tareas. Esto centraliza el contexto compartido, evita duplicaciones y permite cambios globales: si actualizas la skill de diseño, todas las tareas que la usan se benefician. El quinto nivel es el ecosistema: buscar skills gratuitas en el directorio de Anthropic (Notion, Figma, Atlassian) y en skills.sh de Vercel, ordenado por número de instalaciones. Antes de instalar una skill de terceros, pide a Claude que la revise por seguridad, ya que puede contener código. Y adáptala a tu forma de trabajar en lugar de usarla tal cual.

El sexto nivel es el más contraintuitivo y quizá el más importante: cada seis meses, borra tu cloud.md, tus skills y tus hooks, y prueba a hacer la tarea sin ellos para ver si el modelo ha mejorado. Boris Cherny, creador de Claude Code, recomienda esta poda periódica para evitar el 'hobbling' (atar al modelo): instrucciones que antes eran necesarias pueden limitar a modelos más potentes. Anthropic recortó más del 80% de las instrucciones de sistema en Claude Code sin pérdida de rendimiento. El criterio para recortar es claro: elimina los pasos que explican cómo hacer algo (el modelo ya lo sabe), conserva datos, marca, definiciones y correcciones (lo que el modelo no puede saber). Para detectar lo que sobra, haz una tarea con y sin la skill y compara resultados; si sale igual o mejor sin ella, recórtala.

El ecosistema de skills gratuitas: las diez joyas de código abierto para Claude Code

Mientras Anthropic marca la filosofía, la comunidad construye el catálogo. Aztec Lab recopila las diez skills de código abierto con más estrellas en GitHub, ordenadas de menor a mayor popularidad. Todas son gratuitas y se instalan en Claude Code con comandos específicos. La primera es Humanizer (más de 73.000 estrellas), que elimina las señales de texto generado por IA basándose en una guía de Wikipedia que detecta 26 señales. Úsala antes de publicar un post, mandar un correo o subir la descripción de un video. Se instala con dos comandos: /plugin marketplace add blader/humanizer y /plugin install humanizer@humanizer. Si tu Claude Code es antiguo, el comando alternativo es npx skills add blader/humanizer --global --agent claude-code. En una prueba ciega, los jueces prefirieron su versión 16 de 16 veces.

La segunda es Awesome Claude Skills (80.000 estrellas), una colección de más de 1000 skills y plugins ordenados por tema. Incluye el plugin 'Connect Apps', que permite conectar Claude con más de 1000 aplicaciones (correos, tareas, Slack) usando una llave gratuita de Composio. El autor del video probó pidiendo a Claude que mandara un correo y funcionó tras conectar Composio; reinicia Claude después de instalarlo. La tercera es HyperFrames (casi 90.000 estrellas), el editor de video con IA de HeyGen, gratis y de código abierto. Permite crear videos describiéndolos a Claude, a partir de grabaciones o referencias, y editar por partes sin reiniciar: si algo no te gusta, pide cambios específicos como 'título más grande' o 'corte más rápido'. Se instala con npx hyperframes. El propio video de Aztec Lab fue creado con HyperFrames.

La cuarta es Impeccable (116.000 estrellas), una skill de diseño que proporciona vocabulario y comandos concretos para mejorar interfaces generadas por IA. Incluye 24 comandos, un detector de 62 reglas de diseño IA, revisión de accesibilidad y rendimiento. Funciona mejor con objetivos pequeños: en lugar de pedir 'que se vea mejor', usa comandos como 'más llamativo', 'más sobrio' o 'pulir', y empieza criticando una sola sección (por ejemplo, precios) en vez de toda la página. Se instala con npx impeccable install. La quinta es Claude Mem (casi 120.000 estrellas), que añade memoria persistente a Claude entre sesiones. Un segundo agente toma notas y crea un índice de lo importante, permitiendo búsquedas posteriores y evitando repetir contexto. Para proyectos largos es ideal: puedes preguntar qué se decidió la semana pasada sobre algo y lo encuentra. Usa etiquetas de privado para evitar que se guarde información sensible. Se instala con un solo comando (ver README).

Diseño, documentos y metodologías de ingeniería: las skills que convierten a Claude en un equipo completo

La sexta es UI/UX Pro Max (154.000 estrellas), una skill de diseño que genera el sistema visual completo de un proyecto —estructura, estilo, colores, fuentes, disposición de botones— basado en 80 estilos de interfaz y 194 tipos de producto. Le dices a Claude qué tipo de negocio es y la skill escoge estilos, colores y fuentes adecuadas, explicando por qué. Se instala con dos comandos (ver README). La séptima son las Skills oficiales de Anthropic (200.000 estrellas), que incluyen habilidades para crear y editar documentos Word, PDF, PowerPoint y Excel, además de Skill Creator para hacer tus propias skills y otras para diseño de páginas, guías de marca y conexión con herramientas. Se agregan como plugin en Claude Code y escoges cuál instalar.

La octava es Superpowers (326.000 estrellas), una metodología completa para que Claude trabaje como un equipo de ingeniería. Cuando le pides construir algo, primero pregunta qué quieres y por qué, luego muestra el diseño por partes para aprobar, arma un plan en tareas de 2 a 5 minutos con verificación, y al decir 'DELE' pone subagentes a trabajar. No hay que activar nada: las skills se disparan solas. Según sus creadores, es normal que Claude trabaje solo un par de horas sin salirse del plan, revisando cada tarea. La novena son las Skills de Matt Pocock (332.000 estrellas), una colección para 'ingenieros de verdad'. Destaca 'Grill Me', que hace que Claude te entreviste sin piedad antes de lanzar cualquier cosa para detectar cabos sueltos; 'Handoff', que resume la conversación en un documento para otro agente; y 'Teach', para aprender un tema en varias sesiones. Se instalan con un solo comando desde el directorio oficial de plugins de Claude.

La décima y más popular es REA (Reverse Engineer Anything, 478.000 estrellas), que permite investigar cómo funciona una función de una aplicación sin tener su código, explicar su funcionamiento y ayudar a construir una versión para tu proyecto. Funciona con apps de escritorio, JavaScript y sitios web, y corre localmente. El ejemplo que da Aztec Lab es elocuente: su propia página rastreó cómo Notion maneja el copiar y pegar, desde la ventana hasta el fondo de la aplicación. Úsala solo con software propio o con permiso, y bájala únicamente del repositorio oficial o de rea.tools.

Advertencia de seguridad y el futuro del 'hobbling': lo que debes revisar antes de instalar

La popularidad de las skills tiene un lado oscuro: una skill corre con los mismos permisos que tu Claude Code, así que instalar solo lo que venga de una fuente confiable no es una recomendación opcional, es una necesidad. Antes de instalar una skill de terceros, pide a Claude que la revise por seguridad, ya que puede contener código malicioso. Y aunque el ecosistema es vibrante —más de 70 plataformas han adaptado el formato abierto de skills, lo que permite importarlas desde Codex, Cursor y otras IA—, la portabilidad también multiplica los riesgos si no se verifica el origen.

El otro gran desafío es el 'hobbling'. Las skills que hoy son útiles pueden convertirse en lastres mañana. Boris Cherny recomienda borrar cloud.md, skills y hooks cada seis meses para evitar atar al modelo. Anthropic recortó más del 80% de las instrucciones de sistema en Claude Code sin pérdida de rendimiento, lo que demuestra que menos puede ser más. El criterio para recortar es quirúrgico: elimina los pasos que explican cómo hacer algo (el modelo ya lo sabe), conserva datos, marca, definiciones y correcciones (lo que el modelo no puede saber). Para encontrar lo que sobra, haz una tarea con y sin la skill y compara resultados; si sale igual o mejor sin ella, recórtala.

En última instancia, el mensaje de ambos análisis converge: el genio (el modelo) cada vez necesita menos explicaciones de pasos, pero sigue necesitando datos, marca, definiciones y correcciones que solo tú puedes aportar. Las skills son el mecanismo para transmitir ese 'oficio' sin ahogar al agente. La clave está en la curaduría: crear con ejemplos, convertir sesiones en habilidades, grabar lo visual, modularizar el contexto, importar con criterio y podar sin piedad. Ese es el nuevo trabajo del ingeniero de IA.

Claves prácticas para recordar

  • Para crear una skill: pide a Claude que use Skill Creator con ejemplos de tu trabajo; para tareas repetitivas, realiza la tarea una vez y pide que convierta la sesión en skill.
  • Para grabar una skill visual: usa el botón + de la app de Claude o graba con OBS Studio y sube el video con una skill de transcripción segundo a segundo.
  • Para evitar 'hobbling': cada 6 meses borra cloud.md, skills y hooks; elimina pasos explicativos y conserva datos, marca, definiciones y correcciones.
  • Para instalar skills de terceros: revisa el código con Claude antes de instalar y descarga solo de fuentes oficiales; una skill corre con los mismos permisos que tu Claude Code.
