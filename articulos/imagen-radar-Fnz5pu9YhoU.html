Tres códigos SREF de Midjourney para generar arte psicodélico con un solo prompt

Por Thaeyne 2026-11-10
▶ Ver video original en YouTube ↗

Ver en YouTube: 3 psychedelic SREF codes (Thaeyne [Short])

El video muestra tres códigos SREF (6545, 7492 y 7534) para Midjourney que producen estilos psicodélicos distintos: desde retratos con brillo neón hasta patrones intrincados y paisajes cósmicos. Cada código se acompaña de un prompt completo con parámetros de relación de aspecto, versión, alta definición y semilla para replicar los resultados. Es un tip rápido y visual, sin explicación hablada, que sirve como atajo para explorar estéticas psicodélicas en Midjourney.

  • Usa el código SREF 6545 para un estilo psicodélico con brillos neón y rostros estilizados: prompt completo: --sref 6545 --ar 9:16 --v 8.2 --hd --seed 777
  • Usa el código SREF 7492 para un estilo psicodélico más complejo con patrones arremolinados, formas orgánicas y colores contrastantes: prompt completo: --sref 7492 --ar 9:16 --v 8.2 --hd --seed 777
  • Usa el código SREF 7534 para un estilo psicodélico cósmico y surrealista con planetas, ruinas y figuras solitarias: prompt completo: --sref 7534 --ar 9:16 --v 8.2 --hd --seed 777
  • El autor presenta tres códigos SREF con resultados visuales distintos: el 6545 produce retratos con brillo neón y texturas glossy; el 7492 genera patrones intrincados con formas orgánicas y colores vibrantes; el 7534 crea paisajes cósmicos y surrealistas con planetas y ruinas. No se realizan comparaciones ni experimentos más allá de la demostración visual.
