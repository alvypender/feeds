NVIDIA DGX Spark en portátil: la prueba definitiva de IA local con modelos de 120B, generación de vídeo, voz y música sin nube

Por Xavier Mitjana 2026-11-01
▶ Ver video original en YouTube ↗
Un portátil con NVIDIA DGX Spark y 128 GB de memoria unificada demuestra que la IA local ya es viable: ejecuta Nemotron 3.5 Super (120B) para analizar informes de 100 páginas, genera imágenes con Flux 1 Schnell, vídeo con LTX 2.5, clona voz con Qwen 3 TTS y crea música con MiniMax Music 3, todo gratis y sin suscripciones. El test agéntico con Hermes y Qwen 3 27B programa una web completa en 4 horas. Veredicto: excelente para texto y privacidad, pero para gráficos intensivos un sobremesa con GPU dedicada sigue siendo más rápido.

Xavier Mitjana: Toda la IA que necesitas se puede EJECUTAR en un PORTÁTIL (IA GRATIS e ILIMITADA)

La promesa de la IA local: 128 GB de memoria unificada en un portátil

Xavier Mitjana analiza el Asus ProArt P16, un portátil equipado con el procesador NVIDIA DGX Spark, que integra 128 GB de memoria unificada compartida entre CPU y GPU. Esta arquitectura permite cargar modelos de lenguaje de hasta 120 mil millones de parámetros, algo imposible en una GPU convencional como la RTX 5090, que solo dispone de 32 GB de VRAM. El equipo, con pantalla OLED 4K y un diseño ligero, se posiciona como una estación de trabajo portátil para IA local.

El precio del modelo probado ronda los 7000 €, comparable al de una GPU 5090 de gama alta, aunque existen versiones con menos memoria desde 3500 €. Mitjana destaca que este portátil puede reemplazar varias suscripciones de IA en la nube, que fácilmente superan los 70 € al mes, y ofrece ventajas como privacidad, estabilidad y ausencia de límites de uso. Sin embargo, para tareas gráficas intensivas, un sobremesa con GPU dedicada sigue siendo más rápido, por lo que recomienda mantener alguna suscripción en la nube para trabajos muy exigentes.

Análisis de documentos largos: Nemotron 3.5 Super y un millón de tokens de contexto

El primer experimento consistió en procesar un informe anual de Mercadona de más de 100 páginas con el modelo Nemotron 3.5 Super, un modelo de lenguaje de 120B parámetros desarrollado por NVIDIA, gratuito y de aproximadamente 70 GB. Gracias a la memoria unificada, el portátil puede manejar una ventana de contexto de 1 millón de tokens, lo que permite introducir documentos extensos sin fragmentación.

Mitjana solicitó un análisis estructurado en ocho bloques (financiero, operativo, capital humano, sostenibilidad, etc.) y el modelo generó un informe detallado. Para verificar su precisión, utilizó Claude como auditor externo, que confirmó un 100% de éxito en la extracción de datos, aunque detectó pequeñas imprecisiones en la interpretación y un desfase en la paginación. El resultado, según el autor, es impresionante para un modelo local: cientos de cifras extraídas correctamente y una capacidad de razonamiento que rivaliza con modelos en la nube.

Generación de imagen y vídeo: Flux 1 Schnell y LTX 2.5 en ComfyUI

Para la generación de imágenes, Mitjana utiliza ComfyUI, un programa gratuito que permite construir flujos de trabajo personalizados con modelos de código abierto. Con Flux 1 Schnell, de Black Forest Labs, genera una imagen de 1 megapíxel en pocos segundos, con calidad realista y usable. También prueba la edición de imágenes: elimina el texto de una caja con un prompt como «En la imagen de referencia, elimina el texto de la caja», obteniendo un resultado milimétrico.

En vídeo, emplea LTX 2.5, un modelo rápido y de alta resolución que incluye audio. A partir de una imagen de referencia y un prompt, genera un clip de 10 segundos en alta definición. El autor señala que funciona bien, aunque el portátil no es ideal para tareas gráficas intensivas; un sobremesa con GPU dedicada reduciría los tiempos de renderizado. Aun así, la calidad es suficiente para prototipos y proyectos personales.

Clonación de voz y música: Qwen 3 TTS y MiniMax Music 3

La clonación de voz se realiza con Qwen 3 TTS, un modelo de texto a voz que requiere solo 13 segundos de muestra de audio. Mitjana clona su propia voz y genera un archivo MP3 con el texto deseado. El resultado es muy fiel y útil para borradores de voz en off, aunque para calidad final sugiere recurrir a plataformas especializadas. El proceso se ejecuta íntegramente en ComfyUI, sin conexión a internet.

Para la música, utiliza MiniMax Music 3, que a partir de una descripción de género (por ejemplo, rock español) y una letra genera una canción completa en aproximadamente un minuto. El resultado es utilizable y demuestra la versatilidad del portátil para tareas creativas. Ambos modelos son gratuitos y de código abierto, lo que refuerza la propuesta de IA local sin costes recurrentes.

Test agéntico: Hermes y Qwen 3 27B programan una web completa

El experimento más ambicioso es un test agéntico de programación. Mitjana emplea Hermes, un agente de IA gratuito compatible con cualquier modelo, junto con Qwen 3 27B, un modelo denso de 27 mil millones de parámetros. El objetivo: crear una web completa para una aplicación ficticia llamada Fridflow en un solo prompt. El agente debía diseñar la web, escribir el copy de marketing, generar imágenes mediante Magnific MCP (un servicio externo de generación de imágenes vía MCP) y auditar su propio trabajo.

El proceso tardó aproximadamente 4 horas y el resultado fue una web funcional con página de precios, recetas y una demo interactiva. Sin embargo, presentó pequeños fallos de diseño, como que solo se podían seleccionar los días lunes y martes. Para ser un modelo local pequeño y en una sola iteración, el autor considera que el resultado es muy bueno, aunque requeriría más iteraciones para pulir la funcionalidad. Este test demuestra que los agentes locales pueden automatizar tareas complejas de desarrollo web con mínima intervención humana.

Balance: ¿reemplaza la nube o es un complemento?

La conclusión de Mitjana es matizada. El portátil con DGX Spark es excelente para modelos de lenguaje grandes (hasta 120B) y permite una IA local sin suscripciones, con ventajas de privacidad y estabilidad. Para generación gráfica (imagen y vídeo) no es tan rápido como un sobremesa con GPU dedicada, pero es funcional y suficiente para muchos casos. El precio de 7000 € es alto, pero comparable a una GPU 5090; las versiones desde 3500 € amplían el acceso.

El autor recomienda mantener alguna suscripción en la nube para tareas muy exigentes y por la comodidad de acceso desde cualquier dispositivo. No obstante, para quienes priorizan la privacidad, la ausencia de límites o el trabajo desconectado, este portátil representa un salto cualitativo: la IA local ya no es un juguete, sino una herramienta productiva capaz de analizar documentos, generar contenido multimedia y programar aplicaciones con agentes autónomos.

Claves prácticas para recordar

  • Para cargar modelos de 120B en el Spark, asegúrate de ajustar la memoria reservada para la GPU en la aplicación de NVIDIA (por defecto Windows reserva solo una parte).
  • Prompt para eliminar texto en una imagen: «En la imagen de referencia, elimina el texto de la caja».
  • Para clonar voz con Qwen 3 TTS: proporciona una muestra de audio de 13 segundos y luego el texto deseado; el resultado es un MP3.
  • Para un test agéntico de programación: usa Hermes con Qwen 3 27B y un prompt único que incluya diseño, copy, generación de imágenes vía MCP y auditoría; puede tardar horas pero funciona sin intervención.
