Claude Code crea animaciones cinematográficas con una skill gratuita y mejora el audio con Gemini y Lyria

Por Paul J Lipsky 2026-11-17
▶ Ver video original en YouTube ↗
Claude Code deja de ser solo un asistente de código y se convierte en un estudio de animación: con una skill gratuita y un prompt listo para copiar, genera videos 3D consistentes en minutos. El modelo Opus 5.5 Medium es suficiente para la mayoría de proyectos, aunque Fable 5.2 gana cuando hay humanos con extremidades. El audio nativo se queda corto; la API de Gemini y Lyria de Google elevan voces y música a nivel cinematográfico, y la clave puede salir gratis con la suscripción de Google AI.

Del prompt genérico a la skill que lo cambió todo

La primera incursión de Paul J Lipsky en la generación de animaciones con Claude fue decepcionante: los prompts genéricos producían resultados pobres y poco consistentes. El punto de inflexión llegó cuando empaquetó el proceso en una skill personalizada y gratuita que Claude Code puede invocar directamente. La skill no es magia, sino una guía estructurada que fuerza al modelo a seguir un flujo de trabajo probado: definir el tema, elegir un estilo visual, planificar escenas y renderizar el resultado en HTML y MP4.

El flujo es engañosamente simple. Basta con pedirle a Claude que cree una animación o una animación 3D, describiendo el tema y la duración deseada. La skill se activa y comienza a hacer preguntas: qué estilo de animación prefieres (por defecto storybook) y si quieres planificar escena por escena o ir directo al trabajo. Para quien prefiera no instalar nada, el autor también publicó el prompt exacto en un documento de Google que se puede copiar y pegar en Claude para obtener resultados similares.

La elección del modelo marca la diferencia. Opus 5.5 Medium es el caballo de batalla recomendado para la mayoría de proyectos: equilibra calidad y costo. Fable 5.2 ofrece mejores resultados, pero es más caro, por lo que conviene reservarlo para proyectos importantes y no desperdiciar cuota. Hay una excepción clave: si la animación incluye personajes humanos con brazos y piernas, Opus 5.5 tiende a fallar en las extremidades, y Fable 5.2 maneja esos casos con soltura.

Estilos visuales: cómo encontrar el look cinematográfico

La skill incluye estilos predefinidos que van desde el storybook hasta el fotorrealismo, pasando por el estilizado, el retro y el Constellation Line Art, un estilo de líneas que simulan constelaciones y que el autor destaca por su versatilidad. Pero la verdadera potencia llega cuando se exploran referencias externas: buscar imágenes o videos que gusten y decirle a Claude «usa este estilo» con un enlace o una descripción. También funciona buscar nombres de estilos 3D en la web y pasárselos al modelo como referencia.

El autor publicó además una skill de estilo bonus que bloquea un estilo visual específico muy versátil, útil para quienes quieren un look consistente sin tener que describirlo en cada prompt. La combinación de la skill principal con esta skill de estilo permite mantener coherencia visual a lo largo de varios proyectos, algo crítico cuando se trabaja en serie o se necesita una identidad gráfica reconocible.

Pruebas reales: de una hoja arrastrada por un avión a un ejército de robots

Los experimentos del autor demuestran la versatilidad del sistema. Una de las animaciones más logradas muestra una hoja que cae de un árbol y es arrastrada primero por un coche, luego por gansos y finalmente por un avión; el resultado, de aproximadamente 1 minuto y medio, fue muy satisfactorio. También generó un ejército de robots marchando y un video explicativo sobre cómo un proyecto de ley se convierte en ley, lo que evidencia que la herramienta sirve tanto para ficción como para contenido educativo.

El formato de salida es doble: un archivo HTML que permite visualizar la animación en el navegador y un archivo .mp4 que constituye el video final listo para publicar. Esa dualidad facilita la iteración rápida en HTML y la exportación final en MP4 sin necesidad de software de edición adicional.

Audio: donde Claude se queda corto y Gemini y Lyria brillan

La comparación de audio es contundente: la generación nativa de Claude se queda corta frente a la integración con las APIs de Google. El autor pide a Claude que use la API de Gemini para voces en off y efectos de sonido, y que cree un archivo .env para pegar la clave API. La clave se obtiene en aistudio.google.com y puede ser gratuita según la suscripción a Google AI; el autor afirma que nunca ha pagado por su uso.

La seguridad es un punto crítico: nunca se debe compartir la clave API en el chat. Se pega directamente en el archivo .env. Si no se encuentra el archivo, basta con pedirle a Claude que lo abra para poder pegar la clave. Para la música cinematográfica, Lyria de Google ofrece mejor calidad que la generación de audio nativa de Claude, lo que completa un pipeline de audio profesional sin salir del entorno de Claude Code.

Consejos prácticos para no desperdiciar cuota ni tiempo

La recomendación de oro es empezar con Opus 5.5 Medium y la skill gratuita, responder las preguntas de estilo y planificación, y solo escalar a Fable 5.2 cuando el proyecto lo justifique o cuando haya humanos con extremidades. Para explorar estilos, conviene invertir tiempo en buscar referencias visuales antes de lanzar el prompt, porque un buen enlace o una descripción precisa ahorra iteraciones costosas.

El flujo completo —skill, prompt copiable, skill de estilo bonus, Gemini para voces y efectos, Lyria para música— está disponible en los enlaces de la descripción del video, lo que convierte a Claude Code en un estudio de animación cinematográfica de bajo costo y alta consistencia.
