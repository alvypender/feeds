Tres códigos SREF de Midjourney para generar arte con estética pastel

Por Thaeyne 2026-11-18
▶ Ver video original en YouTube ↗

Ver en YouTube: 3 pastel SREF codes (Thaeyne [Short])

El video muestra tres códigos SREF de Midjourney que producen estilos pastel distintos: un paisaje urbano fantástico, arquitectura antigua desértica y retratos de personajes con estilo anime. Cada código se presenta con una imagen de ejemplo y los parámetros exactos para replicarlo. Es un short rápido que sirve como referencia para quienes buscan inspiración en la estética pastel.

  • Usa el parámetro --sref seguido del código para aplicar un estilo de referencia: --sref 5520, --sref 4961, --sref 4382.
  • Ajusta la relación de aspecto con --ar 9:16 para formato vertical (ideal para móviles o redes).
  • Especifica la versión del modelo con --v 8.2 para asegurar compatibilidad con los códigos mostrados.
  • El autor presenta tres códigos SREF con imágenes de ejemplo: el código 5520 genera un paisaje urbano pastel con cielo surrealista; el 4961 produce arquitectura antigua en un desierto con tonos suaves; el 4382 crea retratos de personajes con estilo anime y colores pastel. No se realizan comparaciones ni experimentos más allá de la demostración visual.
