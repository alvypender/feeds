El video es un short que presenta cuatro variaciones de estilo usando el parámetro SREF de Midjourney, manteniendo el mismo prompt, relación de aspecto y semilla. Se muestran los códigos SREF utilizados para cada estilo, permitiendo replicar los resultados. No hay explicación hablada, solo demostración visual con los prompts en pantalla. Es un ejemplo rápido de cómo cambia la estética según el código SREF.

  • Usa el parámetro --sref seguido de un código numérico para aplicar un estilo de referencia en Midjourney.
  • Mantén el mismo prompt, semilla (--seed 777) y relación de aspecto (--ar 9:16) para comparar estilos de manera consistente.
  • Prueba diferentes códigos SREF para obtener variaciones estilísticas sin cambiar el contenido del prompt.
  • Se generaron cuatro imágenes con el mismo prompt 'avant-garde', misma semilla (777) y relación de aspecto 9:16, pero con diferentes códigos SREF (4103853909, 2425178258, 3886620729, 1244711860). El resultado muestra cómo el estilo visual cambia drásticamente según el SREF, manteniendo la composición base. Conclusión: el parámetro SREF es una herramienta poderosa para explorar estilos artísticos sin modificar el prompt.
