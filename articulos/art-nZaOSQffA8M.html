Claude Code se transforma: agentes en paralelo, chats auxiliares y mods sin programar para no desarrolladores

Por Xavier Mitjana 2026-10-28
▶ Ver video original en YouTube ↗
Anthropic ha rediseñado Claude Code para convertirlo en un centro de mando de agentes autónomos: ahora permite lanzar proyectos con un chat coordinador que delega en hilos paralelos, abrir chats auxiliares sin interrumpir la tarea principal, diagnosticar el entorno con /doctor y /skill-doctor, y crear mods personalizados sin escribir una línea de código. La actualización, presentada por Xavier Mitjana, promete que cualquier persona pueda orquestar tareas complejas desde una interfaz visual, aunque exige aprender a gestionar el contexto y la cuota con precisión.

Xavier Mitjana: Claude 2.0 es una locura (todas las novedades explicadas)

Del chat único al centro de mando: la nueva arquitectura de Claude Code

La actualización de Claude Code no es un simple lavado de cara: cambia la forma en que se interactúa con el modelo. Hasta ahora, la herramienta se percibía como un asistente de programación para expertos; ahora se presenta como un entorno de trabajo donde los agentes pueden ejecutar tareas largas y coordinadas. Xavier Mitjana lo deja claro desde el principio: para proyectos extensos, Claude Code es superior a Computer Use porque integra más herramientas —editor de código, navegador— y recibe las novedades antes. La clave está en la nueva vista de plan en forma de checklist, que descompone cada tarea en pasos y los va marcando a medida que se completan, ofreciendo una transparencia inédita sobre lo que hace el agente.

El autor recomienda elegir la opción de trabajo en la nube para que Claude siga ejecutando tareas aunque se cierre la computadora, o activar el control remoto para monitorear el progreso desde el móvil. Esta flexibilidad convierte a Claude Code en un asistente persistente, no en una simple ventana de chat. Además, el anillo junto al selector de modelo se convierte en un panel de control esencial: muestra el consumo de la cuota de 5 horas, el plan semanal y el espacio de contexto disponible. Si el contexto se llena, el comando compact resume la conversación para liberar espacio, una práctica que Mitjana aconseja interiorizar.

Proyectos con hilos paralelos: el chat coordinador que reparte el trabajo

La función más ambiciosa son los proyectos con un chat coordinador. En lugar de una única conversación monolítica, el usuario define un objetivo y el coordinador abre varios hilos de trabajo en paralelo, cada uno con su propio agente. Mitjana lo demuestra con un caso concreto: el lanzamiento de un curso. El coordinador crea tres hilos —temario, ejercicios y página de ventas— que avanzan simultáneamente. Cada hilo deja sus archivos en la pestaña de biblioteca, y el coordinador puede notificar cambios a otros hilos para evitar descoordinaciones. Esta arquitectura imita el trabajo de un equipo humano, pero sin los cuellos de botella de la comunicación.

El flujo es sencillo: se describe el proyecto, se revisa el plan en checklist y se deja que el coordinador delegue. Los hilos pueden consultarse entre sí si pertenecen al mismo proyecto, lo que permite que, por ejemplo, el hilo de ejercicios adapte su contenido al temario generado por otro hilo. Para el autor, esta es la característica que marca la diferencia para tareas complejas y largas, ya que evita la pérdida de información y la descoordinación típica de los chats únicos. Eso sí, exige una buena gestión del contexto: cada hilo consume recursos y el anillo de cuota lo refleja.

Chats auxiliares y visualización múltiple: preguntar sin interrumpir

Otra novedad destacada son los chats auxiliares. Mientras el agente principal trabaja en una tarea, el usuario puede abrir un chat secundario con Command+; (o Ctrl+; en Windows) o desde el menú de tres puntos. Este chat hereda el contexto de la conversación principal, pero no la interrumpe ni la distrae. Es ideal para hacer una pregunta rápida, verificar un dato o pedir una aclaración sin desviar al agente de su objetivo. Mitjana lo prueba y confirma que el chat auxiliar responde con coherencia y luego se puede cerrar sin afectar al hilo principal.

La visualización de múltiples chats va un paso más allá: manteniendo Command (o Ctrl) y haciendo clic en otro chat de la barra lateral, se abren varias conversaciones simultáneas en pantalla. Si pertenecen al mismo proyecto, pueden consultarse entre sí, lo que facilita la coordinación manual. Esta función convierte a Claude Code en una especia de escritorio de agentes, donde el usuario supervisa varios frentes a la vez. Para organizarse, el menú de tres puntos permite agrupar chats en secciones y arrastrarlos por tema, una práctica que el autor recomienda para no perder el hilo.

Diagnóstico y limpieza: /doctor y /skill-doctor para un entorno saludable

A medida que se acumulan configuraciones, conectores, plugins, instrucciones del sistema y skills, el entorno puede volverse pesado y consumir contexto innecesario. Para ello, Anthropic introduce el comando /doctor, que revisa todos estos elementos y propone un plan de limpieza. Mitjana insiste en que no ejecuta cambios sin permiso, por lo que es seguro lanzarlo y revisar las sugerencias. Además, la variante /doctor prompt audita las instrucciones y skills, identificando las obsoletas o contradictorias, lo que ayuda a mantener un comportamiento coherente del agente.

El comando /skill-doctor es complementario: muestra cuánto contexto consume cada skill instalada, cuántas veces se ha usado y cuáles nunca se han activado. Con esa información, el usuario puede desactivar las innecesarias y liberar espacio. En la demostración, el autor descubre varias skills que ocupaban contexto sin aportar valor y las desactiva, logrando un entorno más ágil. Estos comandos son especialmente útiles para quienes experimentan con muchas extensiones y necesitan mantener el rendimiento.

Asesores y mods: personalización sin programar

La actualización también introduce el comando /advisor, que permite configurar un modelo asesor. Mitjana elige Opus como advisor mientras trabaja con Sonnet. Así, Sonnet realiza el trabajo diario y consulta a Opus solo cuando necesita planificar o verificar algo complejo, lo que ahorra cuota del plan. Está en fase experimental, pero el autor comprueba que funciona y que el flujo es transparente: el usuario ve cuándo se consulta al asesor y por qué. Esta configuración es ideal para quienes tienen planes con límites ajustados y quieren reservar el modelo más potente para decisiones críticas.

La guinda es la posibilidad de crear mods sin programar. Basta con describirle a Claude cómo se quiere cambiar la interfaz o la funcionalidad, y la herramienta genera el mod. Mitjana lo demuestra con un ejemplo práctico: un mod que procesa dictados largos y los convierte en instrucciones claras antes de que Claude empiece a trabajar. El proceso es tan sencillo como escribir la descripción y revisar el resultado. Además, se pueden instalar mods de otros desde el botón '+' en plugins, pero el autor advierte que solo deben instalarse de fuentes confiables, porque tienen el mismo acceso que la aplicación. Esta función acerca Claude Code a los no programadores, que pueden adaptar la herramienta a su flujo de trabajo sin tocar código.

Consejos prácticos para exprimir la actualización

A lo largo del video, Mitjana ofrece quince tips que resumen la filosofía de uso. Entre ellos, destaca usar Claude Code en lugar de Computer Use para tareas largas, aprovechar la vista de plan en checklist, elegir la nube para que el agente siga trabajando sin la computadora encendida, y revisar el anillo de cuota para no quedarse sin contexto. También recomienda escribir compact cuando el contexto se llene, organizar los chats en secciones y, en proyectos, delegar en el chat coordinador para que los hilos paralelos hagan el trabajo pesado.

Para consultas rápidas, el chat auxiliar es la herramienta ideal; para supervisar varios frentes, la visualización múltiple. Los comandos /doctor y /skill-doctor deben convertirse en rutina de mantenimiento, y el /advisor permite optimizar la cuota. Finalmente, la creación de mods es la puerta de entrada para personalizar la experiencia sin conocimientos técnicos. Con estas prácticas, Claude Code deja de ser un juguete para desarrolladores y se convierte en una plataforma de automatización accesible, aunque exigente en la gestión del contexto y los recursos.

Claves prácticas para recordar

  • Abre un chat auxiliar con Command+; (Ctrl+; en Windows) para preguntar sin interrumpir la tarea principal.
  • Usa /doctor para auditar configuraciones y /doctor prompt para revisar instrucciones y skills obsoletas.
  • Ejecuta /skill-doctor para ver el consumo de contexto de cada skill y desactivar las que nunca usas.
  • Configura /advisor con Opus como asesor mientras trabajas con Sonnet para ahorrar cuota.
  • Si el contexto se llena, escribe 'compact' para que Claude resuma la conversación y libere espacio.
