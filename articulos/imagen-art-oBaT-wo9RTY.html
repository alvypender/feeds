Google Antigravity 2.0: tutorial completo para crear apps, juegos y motion graphics sin saber programar

Por Paul J Lipsky 2026-11-05
▶ Ver video original en YouTube ↗
Google Antigravity 2.0 convierte prompts en lenguaje natural en aplicaciones funcionales, juegos y motion graphics sin escribir una línea de código. En este tutorial práctico, Paul J Lipsky demuestra que se puede crear una app de notas tipo Notion con archivos Markdown locales en 15 minutos, un juego runner con Godot y Blender instalados automáticamente, y gráficos animados sorprendentes. La clave está en configurar permisos automáticos, elegir Gemini 4 Argon con esfuerzo alto y priorizar la calidad visual en cada prompt.

Una app de escritorio que programa por ti

Google Antigravity 2.0 ha eliminado la interfaz de editor de código para convertirse en una aplicación de escritorio limpia, similar a Gemini, donde el usuario describe lo que quiere y el sistema lo construye. A diferencia de otras herramientas de generación de código, Antigravity puede lanzar las aplicaciones directamente en el ordenador, lo que elimina la fricción de tener que ejecutar comandos o abrir terminales. El tutorial de Paul J Lipsky, pensado para personas sin experiencia en programación, recorre desde la configuración inicial hasta la creación de proyectos completos, incluyendo una app de notas, un juego estilo runner y motion graphics generados únicamente con código.

El primer paso es descargar la aplicación desde el sitio oficial de Antigravity y configurar los permisos. Lipsky recomienda usar el preset 'auto' para que la herramienta no pregunte constantemente por aprobación, o el modo 'turbo' (también conocido como modo YOLO) que elimina todas las confirmaciones. Además, sugiere activar la opción de envío inmediato de mensajes ('send immediately') para poder corregir prompts sobre la marcha sin esperar a que termine la tarea anterior, y la función 'prevent sleep' para que el ordenador no se duerma y detenga las tareas en curso. Para quienes quieran controlar el proceso desde el móvil, existe la opción 'enable remote control' que permite escanear un código QR y supervisar la generación desde otro dispositivo.

Elegir el modelo y crear el primer proyecto

Antigravity permite seleccionar entre varios modelos, incluyendo Gemini 4 Argon, Claude y GPT. Lipsky aconseja usar Gemini 4 Argon con nivel de esfuerzo 'high' para obtener los mejores resultados, aunque consume más cuota. Si se paga por Google Gemini, al iniciar sesión con esa cuenta se obtiene uso adicional dentro de Antigravity. La organización es fundamental: se debe crear un proyecto nuevo por cada app o juego, y cada proyecto se guarda como una carpeta local en el ordenador, lo que facilita el control y la portabilidad.

El tutorial muestra la creación de una app de notas llamada 'Local Notes' con un solo prompt. El autor pidió una aplicación que use archivos Markdown locales como Obsidian pero con una interfaz limpia tipo Notion. Antigravity generó la app en aproximadamente 15 minutos, y el resultado fue muy satisfactorio: funciona como app web local con opción de abrir en un navegador externo. Este experimento demuestra que se puede obtener una herramienta funcional y estéticamente agradable sin conocimientos de programación, simplemente describiendo con precisión el comportamiento y la apariencia deseada.

Juegos con Godot y Blender instalados automáticamente

Para el segundo experimento, Lipsky solicitó un juego estilo runner con un personaje tipo malvavisco en un mundo colorido. Antigravity no solo generó el código, sino que instaló automáticamente Godot y Blender para construir el juego con mejores gráficos. El resultado fue visualmente atractivo y jugable, aunque la mecánica de salto necesitaba ajustes; el autor concluyó que se puede refinar con prompts adicionales. La clave está en pedir explícitamente que se instalen las herramientas necesarias y luego solicitar 'launch the game for me' para ejecutarlo sin usar la terminal.

Este caso ilustra el potencial de Antigravity para prototipar videojuegos de forma rápida. Al integrar motores como Godot y software de modelado como Blender, la herramienta puede generar entornos tridimensionales y personajes con relativa facilidad. Sin embargo, el ajuste fino de la jugabilidad requiere iteraciones adicionales, lo que confirma que el proceso es colaborativo: el usuario describe, la IA construye y luego se pule con nuevos prompts.

Imágenes y motion graphics generados solo con código

El tercer experimento consistió en subir una foto real de una caminata y pedir a Antigravity que la recreara usando únicamente código. El resultado fue sorprendente: la imagen generada incluía detalles como un control deslizante para ajustar el brillo del sol en las gafas y la posibilidad de ver una animación del proceso de pintado. Este tipo de generación demuestra que Antigravity no se limita a aplicaciones funcionales, sino que también puede producir arte digital interactivo y visualizaciones creativas.

Finalmente, el tutorial aborda los motion graphics. Lipsky solicitó un título animado con una lista de capacidades de Antigravity y un diseño minimalista, y otro motion graphic educativo sobre la formación de nubes en estilo claymation de 30 segundos. Ambos fueron generados exitosamente solo con código. Para lograr buenos resultados, recomienda describir la animación deseada, la duración y el estilo con precisión, por ejemplo: 'animated title card', 'claymation style', '30 seconds'. Estas creaciones abren la puerta a la producción de contenido audiovisual sin necesidad de software especializado de animación.

Consejos para mejorar los resultados y evitar comportamientos no deseados

A lo largo del tutorial, Lipsky comparte varias recomendaciones prácticas. Una de las más importantes es incluir en el prompt una instrucción explícita para que la calidad visual sea prioritaria, por ejemplo: 'Visual Quality Is a Top Priority...' (el texto completo está en la descripción del video). También sugiere especificar si se quiere una app nativa (por ejemplo, 'build this as a native Mac app') o una app web local ('build this as a local web app') para evitar que por defecto se cree una app web. Para imágenes, se puede subir una imagen de referencia y pedir 'recreate this image using only code'.

El video también menciona el patrocinio de Fish Audio, una plataforma de voz AI que convierte texto en habla emotiva. Su modelo Drama 3 permite dirigir la entrega con instrucciones en lenguaje natural y ofrece una API para integrar en proyectos. El precio de la API es de pago por uso, sin mínimos mensuales, y tiene un 80% de descuento hasta el 12 de noviembre. Aunque no es el foco principal del tutorial, esta mención añade contexto sobre las posibilidades de integrar voces generadas por IA en las aplicaciones creadas con Antigravity.

Claves prácticas para recordar

  • Para priorizar la calidad visual, incluye en el prompt: 'Visual Quality Is a Top Priority...' (texto completo en la descripción del video).
  • Especifica el tipo de app: 'build this as a native Mac app' o 'build this as a local web app' para evitar que se cree una app web por defecto.
  • Para juegos, pide a Antigravity que instale Godot y Blender si no están presentes, y luego solicita 'launch the game for me'.
  • Para imágenes con código, sube una imagen de referencia y pide 'recreate this image using only code'.
  • Para motion graphics, describe la animación, duración y estilo: 'animated title card', 'claymation style', '30 seconds'.
