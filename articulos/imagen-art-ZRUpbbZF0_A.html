Cómo crear tu propia serie de animación cartoon con IA: el flujo completo con skills de Claude, Higgsfield y Seedance para personajes, escenas y voces consistentes

Por Dan Kieft 2026-11-14
▶ Ver video original en YouTube ↗
Dan Kieft desglosa paso a paso su método para producir un show animado protagonizado por él mismo y su robot Bruiser. La clave está en construir primero una 'foundation' de skills reutilizables en Claude (estilo maestro, personajes, localizaciones, props y prompts de animación) para mantener la consistencia entre episodios. Después genera los assets visuales en Higgsfield con Nano Banana 2.1, escribe los prompts de escena con Claude, y anima con Seedance usando referencias de personaje, localización y voz. Finalmente explica cómo mantener la continuidad entre clips de 17-30 segundos usando los últimos segundos del clip anterior como referencia, y cómo upscalear a 1080p solo al final.

La foundation: skills de Claude para un estilo cartoon consistente

El primer paso para crear una serie de animación cartoon con IA no es generar imágenes, sino definir un estilo visual sólido. Dan Kieft recomienda buscar inspiración en Pinterest con términos como animated sitcom character design y 2D sitcom backgrounds, descargando referencias de series como The Simpsons, Futurama o Rick and Morty. Una vez reunidas en una carpeta, se suben a Claude y se le pide que genere una descripción detallada del estilo: line work, shape language, proporciones, siluetas, expresiones faciales, relaciones de color, shading y lighting. Es fundamental leer y validar ese prompt antes de usarlo, porque será la base de todo el proyecto.

Ese prompt se convierte en un skill maestro llamado cartoon-master-style, guardado como archivo SKILL.md. En Claude, los skills se invocan escribiendo / y seleccionando el skill correspondiente en cada generación de assets. Para mantener la estructura y consistencia, Kieft crea cuatro skills de soporte derivados del maestro: personajes, localizaciones, props y prompts de animación. Además, recomienda crear un Project en Claude (o en Codex/ChatGPT) llamado The Animated Cartoon Show para que todos los chats compartan el contexto del proyecto y no haya que repetir la información en cada conversación.

La escritura de la historia también se apoya en la IA. Kieft utiliza Whisper Flow para dictar a Claude los beats iniciales, luego pide un shortlist y va iterando con feedback hasta bloquear el guion. La estructura final que propone se divide en tres partes: diálogo entre Dan y Bruiser, una segunda parte de desarrollo y un ending con un payoff claro. Este método permite que la narrativa fluya y se mantenga coherente con el estilo visual definido.

Generación de personajes, localizaciones y props en Higgsfield

Con el estilo y el guion listos, el siguiente paso es crear los assets visuales. Para el personaje principal, Kieft sube una foto real suya a Claude, invoca el skill de personaje cartoon y usa el prompt resultante en Higgsfield con el modelo Nano Banana 2.1, en formato 16:9 y resolución 4K. El primer intento no logró un parecido convincente, así que añadió la foto real como referencia de imagen en Higgsfield y describió el cambio de vestuario (por ejemplo, retro bowling outfit) para regenerar solo esa parte. Este truco de superponer la referencia real y describir el ajuste es clave para lograr consistencia facial.

Las localizaciones se generan con el skill /cartoon-location-plate, que puede recibir una imagen de referencia o solo texto descriptivo, como living room con sofá naranja, family home. El proceso es análogo para los props: se usa el skill de props para objetos que aparecerán en escena, como una caja o una laptop. Todos estos assets se generan en Higgsfield con Nano Banana 2.1, manteniendo el mismo modelo para toda la serie, ya que cada modelo tiene sus particularidades y cambiarlo rompe la consistencia visual.

Un aspecto crítico es la composición de escena. Kieft sube los character sheets, la localización y los props a Claude, le pide que lea el cartoon-master-style y que describa qué es cada imagen y qué debe mostrarse en la escena para obtener el prompt final. Luego, en Higgsfield, al añadir referencias, hay que verificar que cada una esté vinculada al elemento correcto del prompt; si no es así, se debe repastear el prompt para forzar el re-link. Este detalle técnico evita que el modelo confunda, por ejemplo, al personaje con un objeto.

Voces y animación con Seedance: referencias estables para cada clip

La voz es un componente esencial para la consistencia de los personajes. Kieft graba menos de 10 segundos de audio propio (o extrae un fragmento de un video) y hace lo mismo para cada personaje. Para Bruiser utilizó Fish Audio, aunque menciona ElevenLabs como alternativa. Sin una referencia de voz, Seedance genera variaciones distintas en cada clip, lo que rompe la ilusión de continuidad. Con la referencia, la voz se mantiene estable a lo largo de la serie.

Para animar, se utiliza Seedance dentro de Higgsfield. El proceso consiste en subir el start frame, la misma imagen como referencia de localización, los character sheets de ambos personajes y ambos audios de voz. En el prompt se describe qué es cada referencia, se indica camera is static as image one y se detalla la performance y el diálogo. Es crucial ser explícito para que el modelo entienda el rol de cada input.

Un consejo práctico muy valioso: usar el modo draft de Seedance, que genera a 480p, para no gastar créditos en tomas malas. Solo cuando el clip está aprobado se hace el upscale a 1080p. El primer clip generado duró 17 segundos y sirvió como base para probar la continuidad con el siguiente. Seedance permite clips de hasta aproximadamente 30 segundos, por lo que para un video de 60 segundos hay que encadenar dos clips con continuidad.

Continuidad entre clips: el truco de los últimos 3 segundos

Mantener la continuidad entre clips es uno de los mayores desafíos. Kieft explica que generar el segundo clip sin referencia del primero rompe la continuidad. La solución es exportar los últimos 3 segundos del clip anterior como un clip separado y subirlo como referencia de video en Higgsfield. Así, el modelo hereda el movimiento y la dirección de la escena. El resto de referencias (personajes, localización, voces) se mantienen idénticas, y solo se añade un close-up si se cambia el ángulo de cámara.

Para continuar la historia, se dicta a Claude con Whisper Flow qué pasa después y se le pide el prompt de la siguiente escena. Este método permite escalar a episodios completos sin perder coherencia. La postproducción final consiste en unir los clips, eliminar silencios y hacer el upscale a 1080p al final. Kieft señala que el mismo método sirve para intros más complejas.

Herramientas clave y conclusiones del flujo

El ecosistema de herramientas es fundamental. Higgsfield actúa como plataforma central de generación de imágenes y video, alojando Nano Banana 2.1 para imágenes y Seedance para animación. Claude (con Projects y Skills) es el cerebro del flujo: almacena el proyecto, ejecuta los skills y redacta todos los prompts. Whisper Flow permite dictar la historia y los prompts sin teclear. Fish Audio y ElevenLabs se encargan de las voces. Pinterest es la fuente de referencias visuales.

Kieft concluye que el factor decisivo no es el modelo, sino la foundation de skills y referencias. Con ese setup se puede escalar a episodios y series manteniendo estilo y personajes. La consistencia se logra fijando un modelo de imagen para toda la serie, usando referencias de voz cortas pero estables, y encadenando clips con los últimos segundos del anterior. El resultado es un flujo de trabajo replicable que permite producir animación cartoon de calidad con IA.

Claves prácticas para recordar

  • Referencia de voz: menos de 10 segundos (una sola frase) por personaje.
  • Continuidad entre clips: exportar los últimos 3 segundos del clip anterior como referencia de video.
  • Modo draft de Seedance: 480p para pruebas; upscale a 1080p solo al final.
  • Skills en Claude: 1 maestro (cartoon-master-style) + 4 de soporte (personaje, localización, props, animación).
