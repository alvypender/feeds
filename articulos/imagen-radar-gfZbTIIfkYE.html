Short sin audio que muestra tres códigos SREF de Midjourney (5497, 6277 y 6080) pensados para obtener resultados de fotografía cinematográfica. Cada ejemplo incluye el prompt completo con parámetros de aspecto 9:16, versión 8.2, modo HD y semilla fija 777 para reproducibilidad. Es un tip rápido y accionable que remite a un video largo del mismo canal sobre fotografía cinematográfica en Midjourney.

  • Usar el parámetro --sref con los códigos 5497, 6277 o 6080 para forzar un estilo fotográfico concreto en Midjourney.
  • Prompt de ejemplo: '. --sref 5497 --ar 9:16 --v 8.2 --hd --seed 777' (repetible con 6277 y 6080).
  • Fijar --seed 777 para poder comparar de forma justa el efecto de cada SREF manteniendo la misma composición base.
  • El autor presenta tres SREF (5497, 6277, 6080) como atajos para obtener look fotográfico cinematográfico, comparándolos bajo parámetros idénticos (--ar 9:16 --v 8.2 --hd --seed 777) para aislar el efecto del estilo.
